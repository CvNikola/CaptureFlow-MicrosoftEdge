CaptureFlow for Microsoft Edge
CaptureFlow is a browser extension project for Microsoft Edge.

Project status: This repository is used to share downloadable builds and release notes. Feature descriptions and screenshots will be added as the extension is finalized.

Download
Visit the Releases page to download the latest available package.

Installation
Temporary installation for testing (Microsoft Edge)
If a release contains a ZIP archive with the extension files:

Download and extract the ZIP archive.
In Microsoft Edge, open about:debugging.
Select This Microsoft Edge.
Click Load Temporary Add-on….
Select the manifest.json file from the extracted extension folder.
Important: Temporary extensions are removed when Microsoft Edge restarts. For a regular, persistent Microsoft Edge installation, the extension generally needs to be packaged and signed through Microsoft Edge extensions.

Updates
New versions and release notes will appear in Releases. Manually installed test versions are not automatically updated from GitHub.

Free and Pro
If a build offers Free and Pro features, any subscription and payment options are presented within the extension. Please refer to the extension's own interface for the current terms.

Feedback and bug reports
Use GitHub Issues to report problems or suggest improvements. When reporting a bug, include your Microsoft Edge version, extension version, and steps to reproduce it. Avoid sharing passwords, payment details, or other personal information.
